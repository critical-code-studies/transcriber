Transcriber

Transcription of recordings and live speech with Whisper, on your Mac or in the browser.

Whisper speech-recognition models by OpenAI. whisper.cpp by Georgi Gerganov and contributors. transformers.js and the ONNX model conversions by Hugging Face. FFmpeg by the FFmpeg developers.

How to use Transcriber

FILE mode

  1. Drop a recording on the page, or use File › Open Recording… (⌘O).
  2. Title, output name and names-and-terms are filled in from the file. With Start as soon as a file is chosen ticked, transcription begins straight away.
  3. In the summary, check Words to check and Possible names. Clicking one adds it to Find and replace; edit the right-hand side and choose Apply current corrections. The transcript is rewritten without transcribing again.

LIVE mode

  1. Press Start recording (⌘R) and allow the microphone. Text appears a few seconds behind speech; grey italic text is provisional.
  2. Click any line to correct it while recording continues. Underlined words are ones the model was unsure of.
  3. Press 1–9 (outside a text field) or click a tag to mark the current moment, or type a tag and press Return. Tags become headings in the Markdown; tags starting with * become inline markers.
  4. Stop and save (⌘S) writes the .md, .srt, .txt and, if chosen, the audio.

Two engines. Opened from the Mac app, transcription uses whisper.cpp with Metal (about 20× real time for files) and saves beside the recording. On the web page it runs in the browser: the model is downloaded once and cached, it is slower, nothing is uploaded, and the files are downloaded at the end. When the web page finds the Mac app running it offers to switch.
